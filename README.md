# SKALD Engine Frontend

Современный, высокопроизводительный веб-интерфейс для интерактивного сторителлинга и ролевых игр с ИИ-персонажами на платформе **SKALD Engine**.

Интерфейс спроектирован с упором на эстетику космического глассморфизма (**Cosmic Glassmorphism**), мгновенный отклик, потоковый стриминг текста в реальном времени (SSE) и древовидное ветвление сюжета с поддержкой свайпов.

## 🛠 Технологический стек

- **Core Framework**: [React 19.2](https://react.dev/) с активным **React Compiler** (`babel-plugin-react-compiler`) для автоматической оптимизации ререндеров и мемоизации.
- **Build Tool**: [Vite 8](https://vite.dev/) с быстрой HMR-разработкой и оптимизированным разделением чанков Rollup.
- **Language**: TypeScript 5.9 (строгий режим типизации, согласованный со схемами Pydantic бэкенда).
- **Routing**: [React Router DOM v7](https://reactrouter.com/).
- **Styling**: Pure CSS Modules + Централизованная дизайн-система токенов (`src/theme/global/tokens.css`). В проекте **не используются** тяжелые фреймворки вроде Tailwind или CSS-in-JS, что обеспечивает максимальную производительность рендеринга.
- **Animations**: [Framer Motion 12](https://www.framer.com/motion/) для плавных микроанимаций и модальных окон.
- **Markdown & Formatting**: `react-markdown` v10 + `remark-gfm` v4 для форматирования сообщений и описаний лора.
- **Data Fetching & State**: Нативный асинхронный `ApiClient` на базе `fetch` с единой обработкой сессий, без сторонних оверхед-хранилищ.

## 🌟 Ключевые возможности

### 1. Каталог персонажей и сценариев (Dashboard)
- Витрина публичных AI-персонажей с живой фильтрацией по фандомам, жанрам и полу.
- Карусель новинок и популярных сценариев.
- Индикаторы новизны и счетчики диалогов.

### 2. Конструктор чат-сессий (CreateChat)
- Два режима старта:
  - **«Песочница»**: свободное общение, настройка динамики отношений, выбор стартовой локации и начального знакомства (`is_acquainted`).
  - **«Сценарий»**: сюжетная игра с контрольными точками (2, 4 или 6 чекпоинтов).
- Прикрепление персоны игрока и кастомных лорбуков.
- Выбор стиля повествования: от первого (`first`), второго (`second`) или третьего (`third`) лица.

### 3. Интерактивный игровой чат (Chat Screen)
- **Потоковый SSE-стриминг**: прием токенов от языковых моделей без задержек.
- **On-the-fly Parser мыслей**: автоматическое извлечение тегов `<Internal_Analysis>...</Internal_Analysis>` в изолированный блок внутренних размышлений персонажа (`ThoughtBlock`).
- **Древовидная история (Tree & Swipes)**:
  - Навигация по альтернативным ответам ИИ (`< 1/3 >`).
  - Регенерация ответа (`POST /messages/{parent_id}/regenerate/stream`).
  - Редактирование любого сообщения (`PUT /messages/{id}`) с созданием новой ветки.
  - Форк диалога (`POST /messages/{id}/fork`) — перенос ветки в отдельный независимый чат.

### 4. Персоны игрока (Personas)
- Создание и редактирование образов пользователя (имя, аватар, возраст, характер, биография).
- Просмотр статистики активности (созданные лорбуки, количество чатов и сообщений).

### 5. Базы знаний (Lorebooks)
- Управление энциклопедиями миров и персонажей.
- Поддержка категорий, приоритетов и тегов.
- Одиночное и массовое (bulk) добавление записей.

### 6. Панель управления (Admin Dashboard)
- Управление персонажами: создание, загрузка аватарок и карточек (`multipart/form-data`), редактирование скрытых полей внешности и личности.
- Управление лорбуками и записями через декомпозированные представления (`LorebookListView`, `LorebookDetailView`).
- Управление пользователями и ролями (`admin`, `moderator`, `user`).
- Управление сюжетными сценариями.

## 🚀 Быстрый старт

### 1. Требования
- **Node.js**: версия 20.x или выше
- **npm**: версия 10.x или выше

### 2. Установка зависимостей
```bash
npm install
```

### 3. Настройка переменных окружения
Создайте файл `.env` в корне проекта (или используйте значения по умолчанию):
```env
# URL API шлюза Gateway (или прямого доступа к сервисам)
VITE_CORE_API_URL=http://localhost:8080/api/v1
VITE_AUTH_API_URL=http://localhost:8080/api/v1

# Уровень логирования фронтенда (DEBUG, INFO, WARN, ERROR)
VITE_LOG_LEVEL=INFO
```

> [!NOTE]
> При локальном запуске без Gateway можно указать прямые порты микросервисов:
> `VITE_CORE_API_URL=http://localhost:8000/api/v1`
> `VITE_AUTH_API_URL=http://localhost:8001/api/v1`

### 4. Запуск сервера разработки
```bash
npm run dev
```
Приложение будет доступно по адресу: **http://localhost:5000**.

## 📋 Скрипты проекта

- **`npm run dev`** — запуск локального Vite сервера разработки с HMR (порт 5000).
- **`npm run build`** — проверка типов через `tsc -b` и сборка продакшен-бандла в директорию `dist/`.
- **`npm run lint`** — проверка кодовой базы линтером ESLint с правилами React Hooks и TypeScript.
- **`npm run preview`** — локальный запуск собранного продакшен-бандла для предпросмотра.

## 🎨 Дизайн-система (Cosmic Glassmorphism)

Стилизация построена на кастомных CSS-токенах в `src/theme/global/tokens.css`:
- **Фон**: глубокий темный космос (`--bg-primary: #05070a`, `--bg-secondary: #0d1117`).
- **Стекло**: акриловые панели с размытием фона (`backdrop-filter: blur(16px)`), светящиеся полупрозрачные границы.
- **Акценты**:
  - Cyan (`#06b6d4`) — активные действия, ссылки, подтверждения.
  - Fuchsia (`#d946ef`) — ИИ-генерация, индикаторы новинок, магия.
  - Indigo (`#6366f1`) — вторичные кнопки и бейджи.
- **Типографика**:
  - UI: `Inter`, `system-ui` (четкость и высокая читаемость элементов интерфейса).
  - Сюжетный текст: `Lora`, `serif` (комфортное литературное чтение).
  - Мысли ИИ: `Playfair Display`, `italic serif` (элегантный акцент монолога персонажа).
